# fc-contract-check

공정거래위원회 정보공개서에서 프랜차이즈의 매출·점포 흐름·창업비용·본사 재무와 계약 조건을 추출하고, 근거와 비교기준을 함께 보여주는 계약 전 사전검토 리포트 MVP입니다.

좋고 나쁨을 판정하지 않습니다. 사용자가 직접 판단할 수 있도록 **사실, 원문 근거, 비교분포**만 제공합니다.

## 만들고 있는 것

예비 프랜차이즈 창업자가 브랜드를 검색하면 다음 내용을 확인하는 서비스가 목표입니다.

- 점포당·면적당 평균매출
- 최근 3년 가맹점 수와 개점·종료·해지 흐름
- 가맹비·교육비·보증금·기타비용·인테리어비
- 가맹본부 재무와 법 위반 정보
- 같은 기준연도·세부 업종 브랜드와 비교한 분포
- 계약기간, 위약금, 경업금지 등 계약·운영 부담
- 모든 값의 정보공개서 원문 근거

현재는 `청담해장국`의 2026-09-14 최종등록 정보공개서에 수록된 2025년 실적을 사용한 단일 리포트 MVP까지 구현돼 있습니다. 실제 원값과 차트는 표시하지만, 동종업계 비교표본이 최소 기준에 미달해 백분위는 보류합니다.

## 현재 진행 상태

### 완료

- FTC 정보공개서 API 구조 및 gzip 응답 처리
- 2017~2025년 공개 목록 3,249건 확인
- 무작위 200건과 초기 탐색 31건, 총 231건 분석
- XML 조항·표 파서 구현
- 계약기간, 최초 가맹금, 경업금지, 독점 영업지역 규칙 구현
- 골든셋 build / label / verify / eval 흐름 구현
- 계약 종료 후 경업금지 기간 50건 사람 검수
- 실제 브랜드 1건의 최신 등록본 기반 로컬 정량 리포트 구현
- 평균매출·점포 흐름·창업비용 구성·본사 재무 시각화
- 데이터 최신성·비교 가능성과 백분위 보류 사유 표시

### 측정 결과

| 필드 | 현재 결과 | 비고 |
|---|---:|---|
| 계약기간 | 228/229 추출 | 약 100% |
| 독점 영업지역 | 225/229 추출 | 98%, 대부분 동일 문구 |
| 최초 가맹금 | 138/226 추출 | 61%, 사람 골든셋 검수 전 |
| 종료 후 경업금지 기간 | 50/50 정확 | 사람 검수 골든셋 기준 100% |
| 경업금지 지역 | 60% | 아직 AI 초안 라벨, 사람 정답 아님 |

경업금지 골든셋의 분포는 제한 없음 25건, 12개월 16건, 24개월 9건입니다. 규칙 성공·미검출을 절반씩 뽑은 층화 표본이므로 모집단 비율 추정용이 아니라 정확도 검증용입니다.

## 프로젝트 구성

```text
.
├── ftc.py                 # FTC API 호출, 캐시, XML 조항·표 파싱
├── collect.py             # 연도별 목록 수집과 무작위 본문 다운로드
├── analyze.py             # 조항 변별력, 추출률, 분포 분석
├── rules.py               # 규칙 기반 필드 추출과 근거 문장
├── golden.py              # 골든셋 생성·라벨링·검수·평가
├── golden/                # 공유 가능한 골든셋 JSONL
├── report-mvp/            # 브랜드 1건 로컬 웹 리포트
└── HANDOVER.md            # 조사 배경, 결정, 정정 이력, 다음 작업
```

`data/`에는 수집한 원문 gzip 캐시가 저장되며 Git에는 포함하지 않습니다. API 키가 들어 있는 `.env`도 커밋하지 않습니다.

## 데이터 탐침 실행

Python 3.9 이상이 필요합니다.

```bash
cp .env.example .env
# .env의 FTC_SERVICE_KEY에 가맹사업거래 사이트 발급 키 입력

python3 collect.py --limit 200
python3 analyze.py
```

특정 조항 원문을 확인할 수 있습니다.

```bash
python3 analyze.py --clause JNG_CTRT_UPDT_PD --dump 5
```

서비스 키는 data.go.kr이 아니라 `franchise.ftc.go.kr` 마이페이지에서 발급받습니다.

## 골든셋 검수와 평가

계약 종료 후 경업금지 기간의 사람 검수 상태를 다시 확인하려면 다음 명령을 사용합니다.

```bash
python3 golden.py verify --spec noncompete --field after_months
python3 golden.py eval --spec noncompete --field after_months --verified-only
```

`after_months`의 기준:

- 계약기간 중 금지만 있고 종료 후 문구가 없으면 `None`
- 계약 종료·해지·해제 후 1년이면 `12`
- 계약 종료·해지·해제 후 2년이면 `24`
- 종료 후 제한은 있으나 기간이 불명확하면 보류

규칙은 사람 라벨링 전에 고치지 않습니다. 같은 사례를 보고 규칙과 정답을 함께 만들면 정확도가 부풀려지기 때문입니다.

## 로컬 리포트 실행

Node.js 22.13 이상이 필요합니다.

```bash
cd report-mvp
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

현재 화면은 공정위 등록번호 `20241145`, 브랜드 `청담해장국`의 2026-09-14 최종등록본을 사용합니다. 실적 기준연도는 2025년이며, 화면 데이터는 2026-09-15에 수동 확인한 스냅샷입니다. 자동 갱신 구조는 아직 아닙니다.

프로덕션 빌드 확인:

```bash
npm run build
```

## 확인된 데이터 함정

- API 응답은 `Accept-Encoding`과 무관하게 gzip으로 올 수 있습니다.
- 본문 루트 엘리먼트 때문에 표준 XML 파서가 그대로 처리하지 못합니다.
- `yr`은 누적 목록이 아니라 해당 연도 등록분입니다.
- 일련번호 순으로 수집하면 같은 가맹본부 브랜드가 표본에 몰립니다.
- 금액 단위는 표 셀이 아니라 표 앞 문장에 있는 경우가 많습니다.
- 약 2.6%는 표준 조항 속성을 따르지 않아 별도 처리가 필요합니다.
- 최초 가맹금에는 합계행 없음, 조건별 금액, 괄호·공백이 섞인 숫자, 단위 누락이 존재합니다.
